# RAG_Based_AI_chatbot

This project is a Retrieval-Augmented Generation (RAG) based AI chatbot built with Langchain and OpenAI. It leverages ChromaDB for vector storage and allows querying over custom documents using natural language.

## 🚀 Features

- 🔎 **Retrieval-Augmented Generation** using Langchain
- 📄 Document ingestion and embedding with `load_docs.py`
- 🧠 Context-aware responses powered by OpenAI models
- 📦 Local vector database with ChromaDB
